# ☕ leet-latte

My LeetCode grind, brewed one problem at a time.

This repo auto-syncs my solved [LeetCode](https://leetcode.com/) problems using [LeetSync](https://github.com/rezaho/leetsync). Every accepted submission gets pushed here automatically, organized and timestamped.

## 📁 Structure

Problems are auto-organized by LeetSync into folders like:

```
/problem-name
  ├── README.md       # Problem description
  ├── solution.py      # My accepted solution
  └── NOTES.md          # Optional: approach, complexity, gotchas
```

## 🎯 Why This Exists

Consistency > intensity. This is my log for:
- Tracking daily/weekly problem-solving progress
- Reviewing past solutions and patterns
- Building a public record of the grind
